## Verified Project Facts

ใช้ข้อมูลชุดนี้เป็นข้อเท็จจริงหลักก่อนส่ง prompt ให้ GPT สร้างภาพ ห้ามให้ภาพสร้างอุปกรณ์หรือ flow ที่อยู่นอกเหนือจากนี้โดยไม่ตั้งใจ

- Project: Thai AI Smart Home Assistant
- Backend: FastAPI
- Web UI: browser dashboard, browser microphone, chat panel, sensor/device/voice node panels
- Local LLM: Ollama
- Current primary demo model: `gemma4:e2b` / Gemma 4 E2B
- Optional/alternative model: Typhoon 2 8B
- STT: faster-whisper, Thai language
- TTS: Edge TTS, Thai voice, browser output MP3, Voice Node output WAV
- Control Node device id: `esp32-01`
- Control Node firmware: MicroPython
- Control Node hardware: ESP32-S3, DHT22, HC-SR501 PIR, 4-channel relay / 4 relay outputs
- Control Node pins from current project config / latest uploaded firmware:
  - DHT22 DATA -> GPIO14
  - Note: if the physical wiring is moved back to GPIO4, update `esp32/config.py`, `data/device_registry.json`, wiring diagrams, and screenshots together before final submission.
  - Relay IN1 -> GPIO5 = ไฟห้องรับแขก
  - Relay IN2 -> GPIO7 = ไฟห้องนอน
  - Relay IN3 -> GPIO8 = ไฟห้องน้ำ
  - Relay IN4 -> GPIO9 = ไฟห้องครัว
  - PIR OUT -> GPIO6
  - Relay active high -> true
- Voice Node device id: `voice-node-01`
- Voice Node firmware: ESP-IDF
- Voice Node hardware: ESP32-S3 N16R8, INMP441 I2S microphone, MAX98357A I2S amplifier, speaker
- Voice Node INMP441 pins:
  - WS / LRCLK -> GPIO16
  - SCK / BCLK -> GPIO17
  - SD / DIN -> GPIO18
  - VDD -> 3.3V
  - GND -> GND
  - L/R -> GND
- Voice Node MAX98357A pins from current firmware:
  - LRC / WS -> GPIO9
  - BCLK -> GPIO10
  - DIN -> GPIO11
  - VIN -> 5V or 3.3V depending on module
  - GND -> common GND
- Voice Node audio:
  - Microphone sample rate -> 16000 Hz
  - Speaker reply sample rate -> 24000 Hz
  - Speaker test tone default -> 880 Hz
- Voice Node current wake flow:
  - Server-side wake detection / handoff to board-talk flow
  - Not full ESP-SR/WakeNet Thai wake word yet
- External services:
  - Weather -> OpenWeather
  - News -> Currents API
  - Navigation -> OpenRouteService, OSRM fallback if available
  - Traffic -> TomTom Traffic
  - LINE -> LINE Messaging API for sending news links/messages
- Important limitation for diagrams:
  - Do not show camera, cloud-only LLM, microphone array, or production database unless explicitly marked as future work
- Do not show API keys or secrets
